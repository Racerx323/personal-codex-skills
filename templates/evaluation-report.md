# Skill evaluation

## Scope

Record the skill tree hash, date, evaluator, and request types.

## Observations

For each case, record the input identifier, actual output, acceptance criteria,
and result. Preserve failures and identify changes made before rerunning.

## Limits

Distinguish static validation, author self-review, independent model execution,
and installed discovery. Do not equate any one of them with a full security audit.
